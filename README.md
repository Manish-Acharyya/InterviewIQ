# 🤖 InterviewIQ.AI

InterviewIQ.AI is an AI-powered mock interview platform built with the MERN Stack. It helps users practice HR and Technical interviews, receive AI-generated questions, submit answers, and review their interview performance through detailed reports.
The project demonstrates practical experience with full-stack development, REST APIs, authentication, AI integration, database management, and deployment.
